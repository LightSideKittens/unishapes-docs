# UniShapes Documentation

Versioned documentation for the UniShapes Unity package, consumed by
[unity.lightside.media](https://unity.lightside.media/unishapes/docs). Every released version is a
`vX.Y.Z` tag in this repository: the site materialises each tag into a documentation version, so a
page committed here reaches readers when the tag it belongs to is published. `pages/HomePage.tsx`
and `pages/GettingStartedPage.tsx` are hand-authored; `api.json` is generated from the package's XML
documentation comments and pushed here by the package's release workflow.
